Комплексный гидравлический, теплотехнический расчёт
и подбор мощности насоса

Панель управления параметрами расчёта

1 Исходные данные

  • Тепловая нагрузка за период (энергия): E = 1600 кВт·ч;
  • Разность температур хладагента: Δt = 20 °C;
  • Геометрические параметры труб: внутренний диаметр d = 53 мм; количество параллельных ветвей N = 1 шт;
  • Высота подъёма жидкости: Hгео = 12 м; общая протяженность одной ветви L = 45 м;
  • Физические константы хладагента: теплоёмкость c = 4.19 кДж/(кг·°C), плотность ρ = 1000 кг/м³.
  • Суммарный коэффициент местных сопротивлений контура: ζ = 5.0;

2 Спецификация и верификация диаметров (Справочные данные)

Условный проход / Тип Внутренний диаметр, мм Скорость потока при текущей нагрузке, м/с Статус при работе N ветвей

3 Расчёт расхода, гидравлики и мощности насоса

3.1 Суммарный требуемый часовой объёмный расход хладагента V для компенсации тепла:

V = (E / (c · ρ · Δt)) · 3600 ≈ 68.74 м³/ч.
(1)

При этом через каждую из N параллельных ветвей протекает расход Vветви = 68.74 м³/ч.

3.2 Фактическая скорость движения потока W в отдельно взятой трубе:

W = (4 · Vветви) / (π · d² · 3600) · 10⁶ ≈ 8.68 м/с.
(2)

3.3 Полный потребный напор насоса Hполн с учётом линейных потерь на трение (λ ≈ 0.025) по закону Дарси-Вейсбаха:

Hполн = Hгео + Hпотери = Hгео + (λ · (L / d) · (W² / 2g)) ≈ 15.20 м вод. ст.
(3)

Потребное избыточное давление в системе составляет ≈ 1.52 бар.

3.4 Требуемая электрическая мощность приводного двигателя насоса Nэл рассчитывается на основе полного расхода и напора:

Nэл = (ρ · g · (V / 3600) · Hполн) / (η · 1000) ≈ 4.37 кВт.
(4)

Где η — полный коэффициент полезного действия насосного агрегата.
